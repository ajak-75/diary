# Ajak

일상과 생각을 가볍게 나누는 스레드형 PWA **Ajak**. 
 짧은 글과 사진·영상으로 오늘을 기록하고, 서로의 하루에 답글을 남깁니다. 접속한 기기의 언어로 UI가 바로 뜹니다.

- **라이브**: https://ajak-75.github.io/diary/
- **브랜드**: **Ajak** — 로고·앱 이름 모두 영문 워드마크
- **성격**: 순백색 라이트 모드 · 미니멀 타이포그래피 · 남녀노소 누구나 쓰는 담백한 스레드형 피드
- **언어**: 접속 기기 언어 자동 감지(`navigator.languages[0] || navigator.language`). 상단 언어 선택 바 없이 바로 그 언어로 뜹니다.
- **기술**: 의존성 없는 바닐라 HTML/CSS/JS. 글은 localStorage, 사진·영상은 IndexedDB에 기기에 저장됩니다. 서버·계정 없음.

## 화면

| 탭 | 내용 |
| --- | --- |
| 홈 | 전체 피드. 비어 있으면 첫 글 작성 안내 |
| 검색 | 본문·태그·닉네임 검색, 실제로 쓴 태그를 세어 보여 주는 인기 태그 상위 8개 |
| 글쓰기 | 새 글 작성 |
| 내 프로필 | 내 글 / 좋아요한 글, 프로필 편집, 📜 커뮤니티 약속 |

## 기능

- **글쓰기·수정**: 텍스트 500자, 해시태그 8개, 사진·영상 4개(영상 15초·15MB 이내). 사진은 1280px·JPEG로 다시 인코딩해 IndexedDB에 영구 저장합니다.
- **피드 상호작용**: 좋아요, 댓글, 리포스트, 공유(링크 복사·기기 공유 시트), 글마다 번역 보기 ↔ 원문 보기 토글.
- **내 프로필**: 프로필 사진 업로드(정사각 256px JPEG), 닉네임 20자, 한 줄 소개 80자. 저장하면 이미 쓴 글·댓글의 닉네임까지 함께 바뀝니다. 기본 이미지는 모노톤 인물 실루엣 SVG.
- **안전장치**: 📜 커뮤니티 약속 5가지(내 프로필 안)와, 글·수정·댓글 등록 시 욕설·혐오·도박·성인·광고 문구, 외부 링크, 전화번호·계좌 같은 개인정보를 걸러 내는 자동 경고 필터.
- **PWA**: `manifest.webmanifest`(이름·약칭 `Ajak`), `sw.js`(캐시 키 `diary-v3`)로 오프라인에서도 열리고, 홈 화면에 설치할 수 있습니다.

## 다국어

| 구분 | 내용 |
| --- | --- |
| 내장 사전 (15개) | 한국어 `ko` · 영어 `en` · 일본어 `ja` · 중국어 간체 `zh` · 번체 `zh-TW` · 스페인어 `es` · 프랑스어 `fr` · 독일어 `de` · 포르투갈어 `pt` · 이탈리아어 `it` · 러시아어 `ru` · 인도네시아어 `id` · 베트남어 `vi` · 태국어 `th` · 아랍어 `ar` |
| 그 밖의 언어 | 실행 중 Google Translate 공개 API로 UI 문구를 한 번 번역해 `localStorage('ajak_ui_i18n_{lang}')`에 캐시(번역 실패 시에만 영어 폴백) |
| 테스트 | `?lang=en` · `?lang=fr` · `?lang=ar` 처럼 쿼리로 언어를 바꿔 확인 |
| 방향 | 아랍어 등 RTL 언어는 `dir="rtl"`로 뒤집힘 |
| 브랜드 | 로고·앱 이름 **Ajak**은 모든 언어에서 영문 그대로 |

`번역 보기`는 접속자의 현재 UI 언어로 옮깁니다(한국어 UI에서 한국어 글은 영어로). 날짜·상대시간(`방금`·`3분 전`)도 그 언어의 표기를 씁니다.

## 파일

```
index.html            화면 골격(헤더 · 4탭 · 시트)
styles.css            흑백 미니멀 스타일
app.js                피드 · 글쓰기 · 미디어 · 번역 · 필터 · 다국어 적용
i18n.js               UI 문구 사전 15개 언어
sw.js                 서비스 워커(diary-v3)
manifest.webmanifest  PWA 매니페스트
icons/                앱 아이콘 · 기본 프로필 이미지 · 공유 커버
```

## 배포

`main` 브랜치 루트를 GitHub Pages로 배포합니다. 별도 빌드 과정은 없습니다.
